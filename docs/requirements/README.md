# Requirements

This directory owns accepted externally meaningful Nutrition Management behavior, constraints and quality expectations.

Current state: no product requirements have been accepted yet.

Rules:
- preserve the observable need separately from a proposed realization;
- mark proposals/unknowns explicitly until accepted;
- do not encode database/API/framework choices as requirements unless their concrete form is itself part of the external contract;
- link to domain/architecture owners rather than duplicating their internal semantics.
