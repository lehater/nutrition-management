# Nutrition Management Core Domain Model

> Generated from Harness canonical knowledge. Do not edit this file directly.

## Purpose

Provide a compact cross-context model of the accepted MVP concepts and invariants for navigation and review.

## Ubiquitous language

- **Household** — Calculation scope containing one or more Household Members.
- **Household Member** — Person whose current Nutrition Profile contributes nutritional demand to the household target.
- **Base Food** — Normalized theoretical food identity used as the nutritional base for commercial Product Cards.
- **Product Card** — Concrete commercial food product linked to one Base Food.
- **Purchase Plan** — Primary recommended 30-day household basket built from executable commercial offers.

## Concepts

### Household

Responsibilities:

- Contain one or more Household Members for calculation.
### Household Member

Responsibilities:

- Contribute one current Nutrition Profile to household nutritional demand.
### Base Food

Responsibilities:

- Own normalized nutrient profile.
- Own food-category membership.
- Own nutrition-data provenance.
### Product Card

Responsibilities:

- Represent a concrete commercial food product linked to one Base Food.
- Own commercial product identity and package quantity.
- Own product-specific nutrient overrides when known.
### Purchase Plan

Responsibilities:

- Recommend one executable 30-day household basket.
- Preserve mapped nutritional coverage, uncertainty, variety and acquisition cost in the result.

## Invariants

- **HOUSEHOLD-NONEMPTY** — A Household contains one or more Household Members.
- **MEMBER-CURRENT-PROFILE** — The MVP keeps one current Nutrition Profile per Household Member.
- **BASE-FOOD-PRIMARY-CATEGORY** — Every Base Food has exactly one primary MVP top-level Food Category.
- **PURCHASE-PLAN-EXECUTABLE-ONLY** — A Purchase Plan selects only executable Product Cards and Offers.
- **PROVIDER-FACTS-AUTHORITATIVE** — Cross-context consumers do not reinterpret provider-owned facts as their own canonical truth.
