# Architecture / project decision records

Use ADRs for consequential accepted choices whose alternatives, rationale, consequences or supersession need durable history.

Naming:

```text
ADR-NNN-short-title.md
```

Recommended sections:
- Status
- Date
- Context
- Decision
- Consequences
- Supersedes / Superseded by (when applicable)

Accepted ADRs are not silently rewritten to represent a different decision. Create a new ADR and mark explicit supersession.

Use `ADR-000-template.md` as the template.
