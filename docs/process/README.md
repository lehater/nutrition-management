# Nutrition Management working protocols

Read only the protocol required by the current task.

- `change-lifecycle.md` — route a non-trivial change to the earliest affected knowledge layer.
- `decision-protocol.md` — classify evidence, proposals, unknowns/conflicts and accepted decisions.
- `document-lifecycle.md` — form, accept, fix, supersede and archive durable project knowledge.
- `domain-change-protocol.md` — classify domain re-entry from new requirements/design/code findings.
- `strategic-ddd-convergence.md` — converge semantic ownership and Bounded Context boundaries.
- `tactical-ddd-stage.md` — model identity/lifecycle/invariants inside an accepted Bounded Context.
- `working-loop.md` — branch/checkpoint/resume mechanics.

Protocols are reusable process. Product truth belongs in `requirements/`, `domain/`, `architecture/` and `decisions/`.
