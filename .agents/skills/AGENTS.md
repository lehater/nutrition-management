# Skills scope

Apply root `AGENTS.md` first.

Skills describe reusable judgement-heavy procedures. They do not own current Nutrition Management product facts.

Rules:
- use the smallest applicable Skill;
- extend an existing Skill before adding an overlapping one;
- keep canonical product/domain/architecture truth in `docs/`;
- keep deterministic structural invariants in validators where practical;
- a Skill may route to a protocol, but must not create a competing lifecycle.
